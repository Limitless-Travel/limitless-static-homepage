# Start coding

Your 60-minute coding window is running. Implement at least one meaningful improvement to the page, focusing on design, UX, or conversion.

## Get started

1. Clone this repository.
2. Open `index.html` directly in your web browser.

There is nothing to install or run. Your finished project must continue to open without dependencies, a server, or a build step. Links, buttons, and forms are intentionally inactive.

## Make your improvement

You may change the HTML, CSS, JavaScript, content presentation, and supplied assets. Use of AI is strongly encouraged, but you remain responsible for the result.

Aim for a focused, polished improvement. Preserve the Limitless Travel brand and check your work on desktop and mobile.

```text
index.html            Page structure and reusable HTML templates
styles/               Shared, responsive, and component CSS
data/                 Content used by repeated components
components.js         Data binding and Web Component registration
fonts/                Local brand fonts
```

Only read [WEB_COMPONENTS.md](./WEB_COMPONENTS.md) if you need to change or create a repeated component.

## Finish

Before selecting **Finish coding** in the assessment form, please test `index.html` on desktop and mobile layouts.

After selecting **Finish coding** and uploading the project, do not change the code any further. You can take any screenshots or other evidence afterwards.
